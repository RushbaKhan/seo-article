Dashboard Structure Overview

Reference for developer Similar to novaxbwms.netlify.app/posts
Screen 0 — Full app map

1. Dashboard Home

  • Today's stats at a glance
  • VC hours tracker (6hr target)
  • Weekly website progress (0/2)
  • Cursor usage summary
  • Today's checklist shortcut
  • Recent submissions

2. My Websites (Posts)

  • All domains / websites table
  • Status: draft / live / rejected
  • Game, GitHub repo, Cloudflare link
  • GSC verified, sitemap, SEO score
  • Add new website button
  • Filter by week / status

3. Daily Log

  • Date + employee auto-fill
  • VC join / leave times
  • Total VC hours today
  • Tasks done checklist
  • Keyword research log
  • End-of-day report submit

4. Weekly Targets

  • Target: 2 websites / week
  • Progress bar per employee
  • Website 1 + Website 2 slots
  • Completion checklist per site
  • Deadline countdown (Friday)
  • Rejected site resubmit flag

5. Cursor Pro Usage

  • Daily / weekly request count
  • Projects worked on list
  • Domain linked to each session
  • Manager review notes
  • Usage warnings if over limit
  • Company work only reminder

6. GSC & Indexing

  • All GSC properties list
  • Verification status
  • Sitemap submitted yes/no
  • Pages indexed count
  • Last checked date
  • Issues / errors alert

7. Reports

  • Daily end-of-day submissions
  • What was built today
  • Domains purchased
  • Blockers / issues field
  • Manager read / unread status
  • History by date

8. Team Overview (Admin)

  • All employees in one view
  • Weekly target per person
  • VC compliance today
  • Websites completed count
  • Cursor usage comparison
  • Approve / reject websites

9. Rules & Policy

  • SEO department rules page
  • VC policy (6 hours/day)
  • Leave policy
  • Domain & ownership rules
  • Website completion checklist
  • Device policy (PC only)
Suggested navigation flow
LOGIN
  └─ Employee Dashboard (home)
       ├─ My Websites ──────► Add / Edit website entry
       │                        ├─ Domain, game, keywords
       │                        ├─ GitHub + Cloudflare links
       │                        └─ Submit for review
       ├─ Daily Log ──────────► VC timer + daily checklist + report
       ├─ Weekly Targets ─────► 2 websites/week tracker
       ├─ Cursor Usage ───────► Log sessions per domain
       ├─ GSC Status ─────────► Monitor indexing per site
       └─ Reports ────────────► End-of-day history

MANAGER (admin role)
  └─ Team Overview
       ├─ See all employees progress
       ├─ Approve / reject websites
       ├─ Review daily reports
       └─ Cursor usage audit

Developer note: Build as a web app similar to BWM (Blog Writing Management). Use auth login, role-based views (employee vs manager), and real-time or daily-updated stats. Each screenshot in this folder shows one screen layout.
