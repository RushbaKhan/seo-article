The Complete Workflow

Below is the full end-to-end workflow for building and deploying one SEO website. Follow every step in order. Skipping steps causes indexing failures.

STEP 1 — Keyword Research

Before buying any domain, you must know what people are searching for.

Use tools like Google Keyword Planner, Ahrefs, Ubersuggest, or manual Google searches.

Look for:

  • High search volume keywords
  • Low to medium competition
  • Game-specific terms (valorant cheats, fortnite hacks, etc.)
  • Long-tail keywords (best valorant esp 2026, undetected fortnite cheat)

STEP 2 — Buy Domain on Cloudflare

Go to Cloudflare Registrar and search for a domain that matches your keyword.

Example: keyword "fortnite cheats" → domain fortnitecheats.com

Rules for domain selection:

  • Keep it short and memorable
  • Include the main keyword if possible
  • Use .com when available
  • Avoid hyphens and numbers when possible

STEP 3 — Build Website on Cursor AI Pro

Open Cursor Pro and create a new project for the domain.

The website must include:

  • Game-specific content and branding
  • Product pages linking to ZADEYO store
  • Blog section with SEO articles
  • Proper metadata (title, description, OG tags)
  • Optimized images with alt text
  • Internal linking between pages
  • A generated sitemap.xml
  • A robots.txt file

Maintain the required UI and structure. Replace all placeholder content with game-specific text, images, and branding.

STEP 4 — Push to GitHub

Cursor Pro generates the code. You push it to the respective GitHub repo.

TERMINAL: git init

TERMINAL: git add .

TERMINAL: git commit -m "Initial site deploy"

TERMINAL: git remote add origin https://github.com/org/fortnitecheats.git

TERMINAL: git push -u origin main

Every domain gets its own repo. Never mix multiple sites in one repo.

STEP 5 — Deploy on Cloudflare Pages

Go to Cloudflare Dashboard → Workers & Pages → Create → Connect to Git.

Select the GitHub repo, set build settings, and deploy.

For static sites, build command is usually empty and output directory is / or dist.

STEP 6 — Connect Domain

In Cloudflare Pages project settings → Custom domains → Add the purchased domain.

Cloudflare auto-configures DNS since the domain is already on Cloudflare.

SSL is automatic. Wait for the certificate to activate (usually a few minutes).

STEP 7 — Google Search Console

Go to Google Search Console.

Add the domain as a property → verify via DNS TXT record on Cloudflare → submit sitemap.xml.

GSC: Add property → Domain → fortnitecheats.com

CLOUDFLARE DNS: Add TXT record for verification

GSC: Sitemaps → Add → https://fortnitecheats.com/sitemap.xml

GSC: URL Inspection → Request indexing for homepage + key pages

Author Note:

I didn't rank my first site by rushing. I followed every step exactly. The sites that fail indexing are always the ones where someone skipped DNS verification or forgot the sitemap.

Keyword Research That Converts

Keyword research is the foundation of every site you build. Wrong keywords = wasted domains. Right keywords = free traffic forever.

1. Start With the Game

Every site targets one game. VALORANT, Fortnite, CS2, Apex — pick one and go deep.

Search patterns follow the game name + intent word:

  • valorant cheats
  • valorant hacks
  • valorant esp
  • valorant aimbot
  • fortnite cheats undetected

2. Analyze Search Intent

Not all keywords are equal. Focus on buying intent.

High intent (target these):

  • "buy valorant cheats"
  • "best undetected fortnite hack"
  • "valorant cheat download"

Low intent (avoid as primary):

  • "what is a valorant cheat"
  • "are valorant cheats real"

3. Check Competition

Search the keyword on Google. Look at who ranks on page 1.

If page 1 is full of massive authority sites (IGN, Reddit, YouTube), the keyword may be too competitive for a new domain.

If page 1 has smaller niche sites, forums, or outdated pages — you can compete.

4. Long-Tail Keywords Win Early

New domains won't rank for "valorant cheats" immediately. Start with long-tail:

  • "valorant esp only cheat 2026"
  • "best private valorant hack undetected"
  • "fortnite soft aim cheat download"

Build blog content around these. As authority grows, target broader terms.

5. Match Domain to Primary Keyword

Your domain should contain or closely match your #1 keyword.

Keyword: "fortnite cheats" → Domain: fortnitecheats.com

Keyword: "valorant esp" → Domain: valorantesphacks.com

Exact-match domains still carry SEO weight in this niche.

6. Document Everything

Before buying a domain, write down:

  • Primary keyword + search volume
  • 5–10 secondary keywords for blog posts
  • Competitor URLs ranking on page 1
  • Your content plan (homepage, product page, 3–5 blog posts)

Author Closing Note

Keyword research is not optional. It is the difference between a site that ranks in 2 weeks and a site that never indexes.

Spend at least 30 minutes on research before every domain purchase.

Common SEO Mistakes

Most SEO employees fail not because they can't build websites, but because of basic mistakes. Read this carefully. These are silent killers.

1. Buying Domain Before Research

❌ Buying a domain because it "sounds good"

❌ No keyword data behind the purchase

Every domain costs money. Research first, buy second.

2. Duplicate Content Across Sites

❌ Copy-pasting the same content on multiple domains

❌ Using identical blog posts across sites

Google penalizes duplicate content. Every site must have unique text, unique images, and unique structure.

3. Forgetting sitemap.xml

❌ Deploying without a sitemap

❌ Not submitting sitemap to Google Search Console

Without a sitemap, Google may never discover your pages. Always generate and submit one.

4. Skipping Google Search Console Verification

❌ Deploying the site and moving on

❌ Not adding the DNS TXT record

A live site with no GSC verification = invisible to Google. Verification takes 5 minutes. Do it every time.

5. Thin Content

❌ Homepage with 200 words

❌ No blog section

❌ Missing product descriptions

Google ranks pages with depth. Aim for 800+ words on key pages and regular blog posts.

6. Missing Meta Tags

❌ No title tag

❌ No meta description

❌ No Open Graph tags

Every page needs a unique title (with keyword) and meta description. This is basic on-page SEO.

7. Broken Internal Links

❌ Links pointing to 404 pages

❌ No internal linking between blog posts and product pages

Internal links help Google crawl your site and distribute ranking power.

8. Ignoring Mobile Responsiveness

❌ Site looks broken on mobile

Google uses mobile-first indexing. If your site fails on mobile, it won't rank.

9. Not Requesting Indexing

❌ Submitting sitemap and waiting forever

After sitemap submission, use URL Inspection in GSC to manually request indexing for your homepage and top 5 pages.

10. Giving Up Too Early

❌ Abandoning a site after 1 week

New domains take 2–8 weeks to start ranking. Keep adding content. Keep monitoring GSC. Patience wins in SEO.

Author Note

I didn't scale by being smart. I scaled by not making these mistakes anymore.

Most people don't fail because they can't build sites. They fail because they skip the boring steps.

Domain Selection Strategy

Choosing the right domain is half the battle. A good domain with decent content will rank faster than perfect content on a bad domain.

1. Keyword-in-Domain Priority

Always prefer domains that contain your primary keyword:

  • fortnitecheats.com ✓
  • valoranthacks.net ✓
  • bestgamingtools.com ✗ (too generic)

2. TLD Selection

Priority order:

  1. .com — always first choice
  2. .net — acceptable alternative
  3. .io — acceptable for tech/gaming
  4. .xyz / .site — avoid unless nothing else available

3. Domain Length

Shorter is better. Aim for under 20 characters.

✓ fortnitecheats.com (16 chars)

✗ best-fortnite-cheats-download.com (too long)

4. Avoid Trademarks

Do not use official game company names in domains if avoidable.

✓ fortnitecheats.com (borderline — game name + generic word)

✗ officialfortnitehack.com (claims official status — risky)

5. Check Domain History

Before buying, check if the domain was previously used:

  • Use archive.org (Wayback Machine)
  • Check if it was penalized or used for spam
  • Avoid domains with bad history

6. Buy Only on Cloudflare

All domains must be purchased through Cloudflare Registrar.

Reasons:

  • At-cost pricing (no markup)

  • Free SSL
  • Fast propagation

7. One Domain = One Site = One Repo

On-Page SEO Essentials

On-page SEO is everything you control directly on the website. Do this right on every single page of every site you build.

1. Title Tags

Every page needs a unique title tag with the primary keyword.

Format: Primary Keyword | Brand Name

Example: Fortnite Cheats - Undetected Hacks 2026 | FortniteCheats

Keep under 60 characters.

2. Meta Descriptions

Write a compelling 150–160 character description for every page.

Include the keyword naturally. Make it click-worthy.

Example: Get the best undetected Fortnite cheats with ESP, aimbot, and wallhack. Safe, private, and updated daily. Buy keys now.

3. Heading Structure

Use proper heading hierarchy:

  • H1 — one per page, contains primary keyword
  • H2 — section headings with secondary keywords
  • H3 — subsections

Never skip levels (H1 → H3 without H2).

4. Internal Linking

Every blog post should link to:

  • The homepage
  • At least one product page
  • 1–2 other blog posts

Use descriptive anchor text: "our valorant esp cheat" not "click here".

5. Image Optimization

Every image must have:

  • Descriptive alt text with keywords
  • Compressed file size (use WebP when possible)
  • Descriptive filename (valorant-esp-screenshot.webp, not IMG_001.png)

6. URL Structure

Clean, keyword-rich URLs:

  • ✓ /valorant-esp-cheats
  • ✓ /blog/best-fortnite-hacks-2026
  • ✗ /page?id=12345

7. Content Depth

Minimum content lengths:

  • Homepage: 800+ words
  • Product pages: 500+ words
  • Blog posts: 1000+ words

More depth = more keywords = more ranking opportunities.

8. Schema Markup (Advanced)

Add structured data where possible:

  • FAQ schema on FAQ sections
  • Article schema on blog posts
  • Product schema on product pages

Ask Cursor Pro to generate JSON-LD schema for each page type.

Cloudflare & DNS Mastery

Cloudflare is our entire infrastructure — domain registrar, DNS, hosting, and SSL. You must be comfortable with every part of it.

1. Cloudflare Registrar — Buying Domains

Dashboard → Domain Registration → Register Domains → search → purchase.

Domains are priced at wholesale cost. Auto-renewal should be ON.

2. Cloudflare Pages — Deployment

Dashboard → Workers & Pages → Create application → Pages → Connect to Git.

Settings for most static sites:

  • Production branch: main
  • Build command: (leave empty for static HTML, or npm run build for frameworks)
  • Build output directory: / or dist

3. Connecting Custom Domain

Pages project → Custom domains → Set up a custom domain → enter your domain.

Since the domain is on Cloudflare, DNS records are added automatically.

Wait for SSL certificate (Status: Active).

4. DNS Records You Should Know

A Record: Points domain to IP (auto-managed by Pages)

CNAME: Points subdomain to Pages URL (auto-managed)

TXT Record: Used for GSC verification and email

NS Records: Nameservers (Cloudflare handles this)

5. SSL/TLS Settings

Cloudflare provides free SSL. Ensure:

  • SSL/TLS encryption mode: Full (strict)
  • Always Use HTTPS: ON
  • Automatic HTTPS Rewrites: ON

6. Common DNS Issues

Site not loading after deploy: Check DNS propagation (can take up to 24 hours, usually minutes on Cloudflare).

SSL error: Ensure SSL mode is Full (strict) and certificate status is Active.

Redirect loop: Check Page Rules and SSL settings.

7. GitHub Integration

Cloudflare Pages auto-deploys on every push to the connected branch.

Workflow: Edit in Cursor → Push to GitHub → Cloudflare auto-builds → Site updates live.

Check deployment logs if a build fails.

Google Search Console Guide

Google Search Console (GSC) is how Google communicates with you. Every site must be verified and monitored through GSC. No exceptions.

1. Adding a Property

Go to search.google.com/search-console

Click "Add property" → Choose "Domain" (not URL prefix).

Enter: fortnitecheats.com (without https://)

2. DNS Verification

Google gives you a TXT record. Add it in Cloudflare:

CLOUDFLARE DNS: Add record

Type: TXT

Name: @ (or domain root)

Content: google-site-verification=xxxxxxxxxx

TTL: Auto

Return to GSC and click Verify. Propagation usually takes 1–5 minutes on Cloudflare.

3. Submitting Sitemap

GSC → Sitemaps → Add new sitemap → enter sitemap.xml

Your sitemap should list all pages:

<?xml version="1.0" encoding="UTF-8"?>

<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">

  <url><loc>https://fortnitecheats.com/</loc></url>

  <url><loc>https://fortnitecheats.com/products</loc></url>

  <url><loc>https://fortnitecheats.com/blog/post-1</loc></url>

</urlset>

4. Request Indexing

After sitemap submission, manually request indexing for key pages:

GSC → URL Inspection → paste URL → "Request Indexing"

Do this for:

  • Homepage
  • Main product page
  • Top 3 blog posts

Google limits daily indexing requests. Prioritize your most important pages.

5. Monitoring Indexing Status

Check weekly:

  • Pages → How many pages are indexed
  • Coverage → Any errors or warnings
  • Performance → Impressions, clicks, average position
  • Core Web Vitals → Page speed issues

6. Fixing Common GSC Issues

"Discovered — currently not indexed": Request indexing manually. Add more internal links to the page.

"Crawled — currently not indexed": Content quality issue. Improve content depth and uniqueness.

"Excluded by noindex tag": Remove noindex meta tag from the page.

"Soft 404": Page has no real content. Add substantial content.

7. Performance Tracking

After 2–4 weeks, check Performance tab:

  • Which keywords are getting impressions
  • Which pages are getting clicks
  • Average position for target keywords

Use this data to decide which sites deserve more content investment.

Author Note

GSC is not optional. It is your direct line to Google.

Every site I rank, I monitor weekly. The data tells you exactly what to fix.
